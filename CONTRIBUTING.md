# Contributions

Les contributions externes sont **fermées au départ** (voir `SPEC.md` §12) : Mirador est un projet personnel, d'abord portfolio, peut-être commercialisé plus tard.

- Le dépôt reste lisible, forkable et modifiable pour un usage permis par la licence (`LICENSE`).
- Merci de ne pas proposer de pull request pour l'instant : elles seront refusées.
- Si les contributions s'ouvrent plus tard, un CLA ou un DCO sera mis en place et ce fichier sera mis à jour.

Pour signaler un bug ou une faille de sécurité, voir `SECURITY.md` (faille) ou l'onglet Issues du dépôt (bug).
